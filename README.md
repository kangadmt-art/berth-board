# DPA Berth Board

Live berthing board for Deendayal Port (Kandla) dry cargo berths CJ-1 to CJ-16, built daily from the DPA berthing list, movement programme and signal sheets.

Live page: https://kangadmt-art.github.io/berth-board/ — one page, four tabs: Cargo jetties · Timber (`#timber` — log vessels: position, laytime / demurrage, completed record) · Tuna (`#tuna`) · Liquid (`#liquid`).

Maintained automatically for Mihir & Company / Neelkanth Group. Updated each morning after the 0700 berthing list and each afternoon after the berthing meeting programme.

Maintaining the board: read `handover/HANDOVER.md` first — where things live, how an update is made, the rules in the projection and the current state. Tools are in `tools/`.
